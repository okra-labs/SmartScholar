# Security and privacy

SmartScholar is a static frontend. It does not include account registration, authentication, email delivery, a server-side database, or backend APIs. GPA calculations, fee estimates, and study tasks are processed in the visitor's browser. The application does not intentionally transmit this information to a SmartScholar backend. CSV exports are created locally when the visitor selects an export button.

The project cannot control how a hosting provider, browser extensions, or a visitor's device handles information. Visitors should avoid entering sensitive personal information. Academic data and estimates should be checked against current official university sources.

To report a security issue, use the repository's private vulnerability-reporting feature if available, or contact the repository maintainers through the channel listed on the project profile.
